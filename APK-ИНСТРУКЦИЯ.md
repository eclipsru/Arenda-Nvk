# APK-ИНСТРУКЦИЯ — приложение «Прокат Инструмента» v2.0 (нативное)

Файл приложения: **ProkatInstrumenta.apk** (лежит в этой папке, а также на сайте — скачивается по кнопке в админ-кабинете). Версия **4.0 (versionCode 9)**.

## Что это за версия

Нативное приложение, главная построена **как в Авито**, в фирменном тёмно-оранжевом стиле:

- **Нижнее меню из 5 кружочков:** Главная · Чат · **[+]** (по центру, крупнее) · Заявки · Кабинет
- **Главная сверху вниз:** поиск с автоподстановкой (выпадающий список вариантов) → квадратные иконки категорий в два ряда (первая «Все категории», по нажатию раскрываются все, первая становится «Скрыть»; выбор категории → подкатегории, первая «Назад») → **карточки по 2 в ряд**: фото, укороченное название, цена/сутки, залог и сердечко избранного справа сверху. Клик по карточке — **полное описание** с кнопкой «В заявку»
- **Услуги** — плиткой «Услуги» в ряду категорий
- **Кнопка «Обновить» убрана** — главная сама обновляется при открытии (и раз в минуту)
- **Чат** — внутренний: клиент пишет магазину, владелец видит диалоги и отвечает; у каждого админа — свои диалоги
- **Заявки:** у владельца — все заявки с кнопкой «Позвонить» и счётчиком новых; у клиента — только его
- **«+»:** у владельца — меню (добавить инструмент / услугу, правка каталога); у клиента — форма заявки
- **Кабинет:** профиль, «Мои заявки», позвонить, адрес выдачи

## Как установить / обновить (2 минуты)
1. Откройте **админ-кабинет на телефоне** (войдите на сайте под eclips.ru@mail.ru) — сверху появится оранжевый баннер «Скачать приложение», нажмите.
2. Либо перекиньте файл ProkatInstrumenta.apk на телефон и откройте его.
3. Телефон спросит про «установку из неизвестных источников» — разрешите (это нормально для приложений вне Google Play).
4. Нажмите «Установить». Поверх версии 1.1 ставится без удаления — данные не теряются.

Требования: Android 5.0 или новее.

Если появится предупреждение Play Protect («приложение не проверено») — «Подробнее» → «Всё равно установить». Это стандартно.

## Как пользоваться
1. Откройте приложение — через секунду откроется экран входа.
2. Войдите (те же e-mail и пароль, что на сайте) или зарегистрируйтесь.
3. Внизу вкладки **Каталог / Услуги** — выбирайте позиции кнопкой «В заявку» (можно несколько, количество меняется в заявке).
4. Кнопка **«Оставить заявку (N)»** внизу → заполните данные, выберите самовывоз или доставку → **«Отправить заявку»**.
5. Готово — заявка в базе, вам придёт уведомление в ВК, позвоним для подтверждения.

Кнопка «Обновить» в шапке каталога подтягивает свежие цены и наличие из базы.

## Для будущих обновлений (важно сохранить)
Подписывать новую версию нужно тем же ключом:
- Файл ключа: **android-app/prokat.keystore**
- Пароль ключа и хранилища: `prokat2026`
- Псевдоним (alias): `prokat`

Если ключ потеряется — обновление не установится поверх старого, придётся удалять и ставить заново. Сохраните файл prokat.keystore в надёжное место.

## Как проверить версию
Внизу экрана входа написана версия приложения (например, «версия 2.3»). Если цифра старее — установите свежий APK с сайта.
