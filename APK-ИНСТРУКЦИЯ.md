# APK-ИНСТРУКЦИЯ — приложение «Прокат Инструмента» v2.0 (нативное)

Файл приложения: **ProkatInstrumenta.apk** (лежит в этой папке). Версия 1.1 — исправлена подпись (v1+v2+v3), теперь ставится и на Android 5.0–6.x, и на новые.

## Что внутри
- Тот же сайт и та же база данных: приложение открывает страницу каталога в фирменном тёмном оформлении, заявки уходят в ВК точно так же, цены и услуги управляются из админ-кабинета.
- Иконка — фирменный оранжевый ключ, тёмный экран запуска без белых вспышек.
- Кнопка «Назад» на телефоне работает как в браузере (шаг назад по страницам).
- Нажатие на телефон в тексте открывает звонилку.
- Загрузка фотографий инструментов в админке работает (открывает выбор файла).

## Как установить на телефон (2 минуты)
1. Перекиньте файл ProkatInstrumenta.apk на телефон (или скачайте из рабочей папки).
2. Откройте файл на телефоне.
3. Телефон спросит про «установку из неизвестных источников» — разрешите для этого приложения (это нормально: приложения вне Google Play всегда так ставятся).
4. Нажмите «Установить» → «Открыть».

Требования: Android 5.0 или новее.

Если при установке появится предупреждение Play Protect («приложение не проверено») — нажмите «Подробнее» → «Всё равно установить». Это стандартно для приложений вне Google Play.

## Для будущих обновлений (важно сохранить)
Чтобы обновлять приложение, подписывать new-версию нужно тем же ключом:
- Файл ключа: **android-app/prokat.keystore**
- Пароль ключа и хранилища: `prokat2026`
- Псевдоним (alias): `prokat`

Если ключ потеряется — обновление не установится поверх старого, придётся удалять и ставить заново. Сохраните файл prokat.keystore в надёжное место.
