# Одна строка = один файл. Сначала имя файла, потом тире и короткое «зачем».
# Сторож tests/keystore-check-guard.cjs читает список в двух направлениях:
#   - любой APK в корне должен быть упомянут здесь или в app-test.json / app-update.json / tools/make-qr.py;
#   - каждая строка отсюда обязана иметь файл в корне (мёртвая строка — ошибка, список не «гниёт»).
#
# Зачем список: на выпущенную для всех версию ведут зелёная карточка в кабинете и баннер на сайте,
# а сама ссылка живёт в базе (app_releases), а не в репозитории. Поэтому сторож про неё не знает,
# и файл легко убрать «как лишний» — вместе с ним у всех пользователей ломается скачивание.
# Проверяет это tests/released-apk-present.cjs (раздел 4.6 в tools/check.sh).
