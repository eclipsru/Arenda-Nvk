# Звук уведомлений приложения «Ива»

Сюда владелец загружает свой звук оповещения (решение 16.10.2026: один звук на все уведомления приложения).

- Формат: `.mp3`, `.ogg` или `.wav`; длина — до 5 секунд; размер — до 1 МБ.
- Как загрузить: на этой странице GitHub → «Add file» → «Upload files» → перетащить файл → «Commit changes».
- Имя файла любое — агент переименует его при сборке.
