# Звук уведомлений приложения «Ива»

Сюда владелец загружает свой звук оповещения (решение 16.10.2026: один звук на все уведомления приложения).

- Формат: `.mp3`, `.ogg` или `.wav`; длина — до 5 секунд; размер — до 1 МБ.
- Как загрузить: на этой странице GitHub → «Add file» → «Upload files» → перетащить файл → «Commit changes».
- Имя файла любое — агент переименует его при сборке.

## Как звук попадает в приложение (с 10.100)

| Файл | Что это |
|---|---|
| `ringtone-sms-notification.mp3` | файл владельца, как загружен (16.10.2026), — не трогается |
| `iva_notify.mp3` | его копия без тегов и картинки-обложки (36 570 байт, MP3 2,27 с); именно она идёт в APK |

- Сборка (`.github/workflows/build-apk.yml`) кладёт `iva_notify.mp3` в APK как `assets/iva_notify.mp3`, а `android/patches/axml_sound.py` добавляет в манифест провайдер `IvaSoundPatch$Files` (`content://ru.prokatnvsk.app.ivasound/notify.mp3`, только чтение) — через него звук берёт система.
- `android/patches/IvaSoundPatch.java`: категории уведомлений получают новые id (`iva_msg_s1` и т. д.) со звуком, старые удаляются. Android 7 и раньше — звук на самом уведомлении.
- Нет файла или провайдера в APK — приложение работает как 10.99 (звук телефона по умолчанию).

### Заменить звук потом

1. Загрузить новый файл сюда.
2. Агент делает из него `iva_notify.mp3` (без тегов) и поднимает `VER` в `IvaSoundPatch.java` (1 → 2). Иначе телефоны оставят старый звук: Android не даёт менять звук у созданной категории.
3. Новая сборка.
