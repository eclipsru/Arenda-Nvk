# Поиск на главной в приложении: «Ваш город», ручка и панель фильтров (тестовая сборка 10.45)

**Статус:** тестовая сборка 10.45 (119) — только в жёлтой карточке владельца на сайте. Выпущенная для всех версия не менялась.
**Ветка:** `arena/1da7609b-arenda-nvk` (PR №32). **Точка отката:** 10.44 = `e216301`.
**Код:** `28126f7` (сборка — бот-коммит `05b6756`, тестовый канал на `main` — `1a8ef39`).

## 1. Что видит пользователь

1. **Строка «Ваш город»** над строкой поиска, справа кнопка «город ▾».
   - При запуске выбран город из профиля клиента. Если в профиле города нет (или это гость) — «Выберите город»; молча ничего не подставляется.
   - Нажатие открывает выбор города: поле поиска, «Все города», города из того же списка, что на сайте (`assets/data.js`, 139), рядом — сколько инструментов сейчас в каталоге в этом городе. Можно ввести свой город, если его нет в списке (проверка «похоже на название» — как на сайте).
   - Выбор сразу перефильтровывает ленту и запоминается **на телефоне** (`prokat_session`, ключ `iva_search_city`). **Город в профиле не меняется.** При выходе из аккаунта штатный выход очищает и этот выбор.
2. **Ручка слева** — тонкая оранжевая полоска в отдельной полосе 24dp у левого края (лента сдвинута, картинка-шапка остаётся во всю ширину).
   - Потянуть вправо — открывается панель (идёт за пальцем), влево — закрывается; нажатие — открыть/закрыть.
   - Если вести пальцем по ручке вверх-вниз — страница прокручивается как обычно. Горизонтальной прокрутки у страницы нет.
   - На Android 10+ ручка исключена из системного жеста «Назад» с края.
3. **Панель фильтров** (поверх главной, затемнение сзади не пропускает нажатия):
   - ✕ в шапке, нажатие на затемнение, движение влево, системная «Назад» — закрывают без применения.
   - Город — показан строкой (смена — тем же выбором города), второго выбора города нет.
   - Категория и подкатегория — те же, что в сетке категорий на главной (одно и то же состояние).
   - Цена за сутки «от / до» (₽), «Только с доставкой», состояние «Новый / Хороший / Рабочий».
   - Сверху — снимаемые фильтры (✕ на каждом).
   - Внизу закреплены «Сбросить» (сбрасывает правку в панели) и «Показать N инструментов» — N считается сразу при каждом изменении по тому же правилу, что и лента (включая текст в строке поиска). При 0 — «Ничего не найдено», кнопка неактивна.
4. Под строкой поиска — ряд применённых фильтров (город, категория, цена, доставка, состояние) с ✕ и «Фильтры» (открыть панель). Без активных фильтров ряда нет.

## 2. Откуда берутся данные (ничего не придумывается)

- **Город инструмента** — как на сайте (`assets/geo.js` + `assets/sb.js`): `pickup_city` → город из `pickup_address` → город из строки «Адрес выдачи:» в условиях → «Новочеркасск» (так же поступает сайт для объявлений без адреса).
- **Город профиля** — по порядку: уже загруженный профиль (экран настроек 10.40) → `rpc/get_my_customer_profile` → `user_metadata.city` из `/auth/v1/user` → город из адреса профиля. Только чтение.
- Если пользователь в этом запуске сам выбрал город, профиль его не перебивает. Изменённый город в профиле (другой, чем в прошлый раз) — выбирается при следующем запуске.
- **Состояние** — из строки «Состояние: …» в условиях объявления (как пишет `new.html`). **Отличие от сайта:** если состояние в объявлении не указано, при выбранном фильтре состояния такой инструмент не показывается.
- **Цена** — поле `price` (за сутки), **доставка** — поле `delivery`. Сданные в аренду (`t_status = rented`) не показываются — как в штатной ленте.
- Карты, радиуса, дат, геолокации нет; разрешение на местоположение не запрашивается.

## 3. Как устроено (для разработчика)

- Новый класс `android/patches/IvaSearchPatch.java`. Новых точек вставки в smali **нет**: всё ставится из `IvaPatch.onTab` (конец штатного `showTab`) — так же, как раздел логотипа 10.43.
- Установка один раз на окно (`ready(a)`), с проверкой разметки 10.14: если что-то не совпало — ничего не трогается, главная работает как в 10.44.
- Лента: отфильтрованный по городу/цене/доставке/состоянию список кладётся в штатное поле `tools`, затем вызывается штатный `renderFeed` (он сам применяет поиск, категорию и подкатегорию). Полный каталог хранится отдельно; когда штатный `loadCatalog` (или «потянуть для обновления») приносит новый список, условия применяются заново.
- Раздел логотипа («Избранное / Мои инструменты») берёт полный каталог (`IvaSearchPatch.allTools`), а не выдачу по городу.
- Чистая логика (город, совпадения, подсчёт, склонения, выбор города профиля, список в выборе города) — статические функции на строках, покрыты `IvaPatchTest`.

## 4. Сторожа

`tests/apk-build-guard.cjs`: класс компилируется в сборке; `onTab` вызывает `IvaSearchPatch.onShowTab`; в `apply.py` нет новых точек; штатные имена (`pageHome`, `searchBox`, `feedGrid`, `renderFeed`, `curCat`…) и ресурсы (`bg_chip`, `bg_search`…) есть в 10.14; `CITIES` в Java = `CITIES` в `assets/data.js`; нет записи профиля (`PUT`, `save_customer_profile`) и геолокации; раздел логотипа берёт полный каталог.
`IvaPatchTest`: +70 проверок (город, адреса, сравнение «г.»/ё, состояние, совпадения ленты, фильтры, цена, склонения, профиль, выбор города).

## 5. Что проверить на телефоне (владельцу)

1. Жёлтая карточка «Новая версия 10.45» → установить поверх (удалять 10.44 не нужно).
2. Под клиентом с городом в профиле: на главной «Ваш город» — этот город, лента только по нему. Под гостем — «Выберите город», лента — все города.
3. Нажать на город → поиск «шах» → выбрать → лента сменилась; перезапустить приложение — город тот же. Открыть «Настройки профиля» — город в профиле **не** поменялся.
4. Потянуть ручку слева вправо — панель идёт за пальцем; отпустить — открылась. Влево — закрылась. Нажать на ручку — открылась, ✕ — закрылась, «Назад» — закрылась.
5. В панели выбрать категорию, «от 300», «Только с доставкой» — число на кнопке меняется сразу; «Показать» — лента и ряд фильтров под поиском совпадают с числом.
6. ✕ на фильтре в ряду под поиском — фильтр снят. Логотип внизу — «Избранное» и «Мои инструменты» как в 10.44. Карточка инструмента, сердечко, вход/выход — как раньше.
7. Если на главной сдвинулось или налезло — скриншот.

## 6. Как откатить к 10.44

- **Код:** `git revert 05b6756 28126f7` и пуш в ветку — сборка сделает **10.46** с кодом 10.44 (её можно ставить поверх: телефон не даёт поставить 10.44 поверх 10.45, номер версии должен расти). В `build-apk.yml` после revert нужно поднять версию до 10.46 / 120.
- **Без новой сборки:** удалить приложение и поставить `ProkatInstrumenta-10.44.apk` (лежит в репозитории, в `app-keep-apks.txt`) — потребуется войти заново.
- **Тестовый канал:** в `app-test.json` на `main` вернуть 10.44 / 118.
- **База, сайт, выпущенная версия** не менялись.
