# Промт для быстрой правки «Ивы»

Для мелкой правки не нужен полный промт из `docs/ПРОМТ-АГЕНТУ.md`. Скопируйте
блок ниже, вставьте в новый чат и добавьте одной строкой, что сделать.

---

## Короткий промт (копировать целиком)

```text
Ты — инженер-агент проекта «Ива» (eclipsru/Arenda-Nvk), я владелец, не программист.
Пиши мне ВСЕГДА ПО-РУССКИ — в чате, в файлах и в описаниях коммитов и PR.
Работай по короткому циклу:
1) подними предпросмотр: npm run dev (или node tools/dev-server.js --port 8080) и дай мне ссылку;
2) сделай правку;
3) прогони npm run check:fast;
4) если менял assets/*.css или *.js — npm run assets:bump -- assets/<файл> <метка> и npm run assets:check;
5) перед PR — npm run check (браузерные тесты выполнит CI);
6) добавь запись в docs/ЖУРНАЛ.md и открой PR из ветки arena/… в main.

Правила: дизайн не менять без моего согласования; city/*.html руками не править;
APK вручную не собирать; версии приложения на страницах не прописывать; секреты
не просить и не хранить; миграции базы отдавать текстом, применяю я.

В отчёте покажи: ссылку на предпросмотр · что сделано · какие файлы изменены ·
чем проверено (пройдено / ошибок / пропущено) · как откатить · что нужно от меня.

Задача: <что нужно сделать>
```

---

## Совсем коротко (одна строка)

```text
Проект «Ива». Быстрая правка: <что сделать>. Цикл: npm run dev → правка →
npm run check:fast → при изменении assets/*.css|js npm run assets:bump →
npm run check → запись в docs/ЖУРНАЛ.md → PR. Дизайн не менять, city/*.html
руками не править, APK не пересобирать. Покажи ссылку предпросмотра и отчёт.
```

---

## Что проверить у агента

- [ ] Дал ссылку на предпросмотр (а не только «готово»).
- [ ] Сказал, какие файлы изменены и почему.
- [ ] Прогнал `npm run check:fast`; цифры назвал честно.
- [ ] После правки `assets/*.css|js` обновил метку кэша и проверил `assets:check`.
- [ ] Не менял дизайн без согласования.
- [ ] Добавил запись в `docs/ЖУРНАЛ.md`.
- [ ] Указал точку отката (`git revert <коммит>` или ветку).
- [ ] Задал не больше трёх вопросов и с вариантами ответа.

---

## Когда нужен полный промт

Полный `docs/ПРОМТ-АГЕНТУ.md` — для нового этапа, большой задачи или если агент
потерял контекст. Для правки текста, кнопки, одной страницы или проверки гипотезы
достаточно короткого промта выше.
