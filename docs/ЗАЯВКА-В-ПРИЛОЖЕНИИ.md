и второй инструмент молча заменял первый. Теперь ключ — настоящий id, инструменты копятся.

## 2. Как устроено

- Штатные строки заявки (`orderLines`) и строка общего срока **скрыты, не удалены**; наши карточки стоят сразу под `orderLines`
  (до «Адрес выдачи»). Штатные `renderOrderLines` / `updateSummary` работают как раньше; сразу после каждого `updateSummary`
  (вызов `IvaPatch.onSummary` в его начале + `post`) перерисовываются наши строки и текст итога `ordSum`.
- Срок инструмента хранится в его строке заявки (`selected`, ключ `iva_days`), количество всегда 1. Штатное поле `days` = самый длинный срок.
- Средняя доставка: штатный расчёт (`calcDelivery`) складывает `км × цена за км` по инструментам; `IvaPatch.onPrice` до «туда и обратно»
  делит сумму на число инструментов с ценой за км (прокат один — километры общие). Добавили/убрали инструмент при введённом адресе —
  расчёт запускается заново.
- «В заявку»: наш обработчик кнопки `detOrder` — проверка проката → штатное добавление (тост, переход в заявку) → ключ по id + картинка + срок.
  Услуги — штатно (только проверка проката).
- «Отправить заявку»: наш обработчик `btnSend` — те же проверки (имя, телефон ≥ 10 цифр, адрес при доставке), один `POST /rest/v1/rpc/submit_order`;
  успех — штатный экран «Заявка отправлена» (штатный `lambda$sendOrder$126`), ошибка — «Не удалось отправить: …», кнопка снова активна.
  Пустая заявка или без входа — штатный `sendOrder` (его подсказки и экран входа).
- Самовывоз в заявке: адрес проката из штатного `admAddr` (раньше в `p_get_method` всегда стояло «ул. Маресьева, 36», даже у другого проката).

## 3. Проверка на телефоне

1. Поставить 10.55 поверх (удалять 10.54 не нужно), войти клиентом с заполненным профилем.
2. Открыть инструмент → «В заявку». В заявке: Фамилия / Имя / Отчество — по своим полям; у инструмента — «Срок аренды · сумма» и «− 1 день +»; выбора количества нет.
3. «+ Добавить инструмент» → карточки только этого проката → выбрать → в заявке два инструмента, у каждого свой срок. Поменять сроки — суммы и «ИТОГО» меняются.
4. Выбрать «Доставка», ввести адрес → доставка ≈ средняя (для двух инструментов с 30 и 50 ₽/км на 12 км — 480 ₽, а не 960 ₽). «Туда и обратно» — ×2.
5. При выбранной доставке «+ Добавить инструмент» → нет инструментов без доставки, есть подсказка. Выбрать «Самовывоз» → список больше.
6. Добавить инструмент без доставки (при самовывозе) → «Доставка» пропала, подсказка «Доставка недоступна: … — только самовывоз».
7. Открыть инструмент другого проката → «В заявку» → вопрос «Заменить?»: «Отмена» — заявка прежняя; «Заменить» — в заявке только новый.
8. Отправить заявку → экран «Заявка отправлена». У админа в заявке: инструменты со сроками («Дрель (3 дня), Пила (5 дней)»), в комментарии — чек со сроком и суммой каждого.

## 4. Не проверено / ограничения

- На телефоне не проверено (эмулятора нет): вид карточек и счётчиков, список «+ Добавить инструмент», подсказки.
- Определение фамилии в одной строке имени (без профиля) — по окончаниям; редкие имена/фамилии могут встать не в те поля — клиент поправит руками.
- `submit_order` в базе не менялся: заявка одна, срок каждого инструмента — в тексте `p_tools` и в чеке; `orders.days` — самый длинный срок.
  Комиссия считается как раньше — по сумме, которую админ закрывает в `order_parts`.
