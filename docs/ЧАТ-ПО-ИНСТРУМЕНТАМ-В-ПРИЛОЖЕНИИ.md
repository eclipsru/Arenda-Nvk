# Чат по инструментам в приложении (10.54)

Тестовая сборка **10.54 (128)**, ветка `arena/1da7609b-arenda-nvk` (PR №32). Код — `android/patches/IvaChatPatch.java`,
вход — `IvaPatch.onTab` (новых smali-хуков нет). Сайт не менялся.

## 1. Что просил владелец и что сделано

| № | Просьба | Как сделано |
|---|---------|-------------|
| 1 | «Спросить об инструменте в чате» — без автосообщения с картинкой и «Вопрос по инструменту» | Наш обработчик кнопки `detAsk`: `chatWith` = владелец инструмента (`detOwner`, иначе eclips.ru@mail.ru), `chatTool` = инструмент, вкладка «Чат». Ничего не отправляется. Админу и без входа — штатный обработчик (подсказка / экран входа). |
| 2 | Чат появляется в списке после первого сообщения клиента; слева аватар проката в кружке и название проката, справа маленькая скруглённая картинка инструмента, время и дата последнего сообщения | Список «Чаты» строится из `app_messages` по паре «прокат + инструмент» (`tool_id`). Аватар — `admins.avatar` (штатный `loadPhoto`, ключ кэша `ava`+почта), иначе буква на `bg_avatar`. Название — `company` → `full_name` → `name` → «Владелец». Справа: время, дата, счётчик непрочитанных, картинка инструмента 44dp (ключ кэша `ctool`+id). Пустая переписка из карточки в список не попадает. |
| 3 | Админ видит аватар клиента | После SQL (раздел 4): `iva_chat_peers()` отдаёт почту и путь к фото клиентов, которые писали этому администратору; фото скачивается штатным `downloadClientAvatar`. До SQL — буква. |
| 4 | Поменять местами карточку инструмента и «Все администраторы», переименовать в «Назад к чатам», закрепить | Над перепиской (вне прокрутки) — карточка инструмента (56dp), под ней «‹ Назад к чатам». Оба элемента закреплены (решение владельца: «оба»). |
| 5 | Круглые аватарки у сообщений | 30dp у каждого сообщения: у проката — аватар администратора, у клиента — своё фото (кэш профиля 10.41), у админа — фото клиента после SQL. |
| 6 | Свои сообщения справа, собеседника слева | Свои — справа (`bg_bubble_me`, аватарка справа), собеседника — слева (`bg_bubble_other`). |
| 7 | Список прокатов оставить под чатами | Под «Чаты» — «Написать прокату»: штатный список действующих администраторов (владелец первым) → общий чат без инструмента. |

Ещё: «Отправить» пишет `tool_id` открытой переписки (колонка в базе уже есть — проверка CI `f7c49aa`; сайт пишет её так же);
если база не примет — повтор без него; при ошибке текст возвращается в поле. Долгое нажатие (голос) — штатное.
Разделители дней, ✓/✓✓, удаление своих (× и долгое нажатие с подтверждением), фото в сообщении, голосовые (штатный `playVoice`).
Владелец (eclips.ru@mail.ru) видит переписки всех администраторов, как в штатном приложении.

## 2. Как устроено

- Штатный `renderChat` работает как раньше (отметка «прочитано», строка ввода `inputBar`), но его прокрутка `chatScroll`
  скрыта; наш слой стоит в том же `pageChat` над `inputBar`. Если наш слой не построился или упал — `chatScroll` снова виден.
- Обновление: штатный опрос раз в 5 с (`CHAT_TICK` → `loadChat`) перерисовывает скрытый `chatList` → наш запрос
  (не чаще раза в 300 мс): `app_messages` (последние 300, с `tool_id`), `admins` (кэш 60 с), `tools?id=in.(…)` (кэш).
  Перерисовка — только если данные изменились (иначе голосовое не прерывается).
- Какая переписка открыта — по штатным `chatWith`/`chatTool` (их меняют и штатные «Написать продавцу», «Написать клиенту»).
- Инструмент сообщения: `tool_id`, иначе метка этого телефона, иначе (только голосовые) инструмент предыдущего сообщения пары.
  Текст без `tool_id` (старые сообщения, старые версии приложения) — общий чат.
- Голосовые: штатная запись `tool_id` не передаёт. Новые свои голосовые в открытой переписке по инструменту помечаются на
  телефоне и (после SQL) в базе через `iva_tag_my_messages`.
- Чистая логика (`buildChats`, `thread`, `assignTools`, `voiceToTag`, `parseIso`, подписи) проверяется `IvaPatchTest` (35 проверок).

## 3. Проверка на телефоне (10.54)

1. Поставить 10.54 поверх 10.53 (тот же ключ №6). Войти клиентом.
2. Открыть карточку инструмента → «Спросить об инструменте в чате». Откроется пустой чат: сверху карточка инструмента,
   под ней «‹ Назад к чатам», подсказка «Напишите вопрос…». **Автосообщения нет.**
3. «‹ Назад к чатам» — в списке этого чата ещё нет. Снова «Спросить…», написать «Здравствуйте» → сообщение справа с вашей
   аватаркой, время под ним.
4. «Назад к чатам» — в списке строка: аватар проката, название, инструмент, «Вы: Здравствуйте»; справа время, дата, картинка
   инструмента. Под списком — «Написать прокату».
5. Спросить про другой инструмент того же проката — это отдельная строка.
6. Войти администратором → «Переписки»: строки по клиенту и инструменту; ответить — ответ справа, у клиента — слева
   с аватаром проката. Фото клиента у администратора — после SQL (до него — буква).
7. Голосовое (долгое нажатие) в чате по инструменту — остаётся в этом чате; воспроизведение — нажатием на пузырь.
