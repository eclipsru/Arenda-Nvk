# Ива — витрина аренды инструмента (этап 1)

Классифайд-витрина в брендинге «Ива». Без сборки: чистый HTML + CSS + JS,
открывается двойным кликом по `index.html` и кладётся на GitHub Pages как есть.

## Файлы

```
market/
  index.html        Главная: поиск, категории, ленты «Рядом с вами» и «Свежие»
  catalog.html      Каталог: фильтры, сортировка, чипы, пустое состояние
  tool.html         Карточка объявления (?id=1..36)
  favorites.html    Избранное
  assets/
    theme.css       Дизайн-система (цвета, компоненты, адаптив)
    data.js         36 объявлений, 9 категорий, 12 подкатегорий, 8 арендодателей
    app.js          Шапка, меню, избранное, поиск, фильтры, шторки
```

## Что работает

- Поиск с подсказками (категории + объявления), Enter и стрелки
- Фильтры: цена от/до, категория, подкатегория, город, состояние, только с доставкой
- Сортировка: новые / дешевле / дороже / по рейтингу
- Состояние фильтров живёт в URL — ссылку можно переслать
- Избранное в localStorage, счётчик в шапке и нижнем меню
- Карточка: галерея со стрелками, миниатюрами, свайпом и клавишами, «Показать телефон», похожие
- Выбор города сохраняется и влияет на блок «Рядом с вами»
- Мобильная версия: нижнее меню, шторка фильтров, шторка городов

## Данные

Демонстрационные (`assets/data.js`). Категории и подкатегории повторяют
структуру реальной базы Supabase, чтобы на следующем этапе подключение
прошло без переделки разметки. Фото — генерируемые SVG-плейсхолдеры,
внешних запросов нет.
